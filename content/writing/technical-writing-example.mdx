## 程式碼

```python
def quantize(x, scale, zero_point=0):
    return (x / scale).round() + zero_point
```

## 數學公式

行內公式：$e = x - \hat{x}$。

$$
\mathrm{MSE} = \frac{1}{n}\sum_{i=1}^{n}(x_i - \hat{x}_i)^2
$$

## 表格與引言

| 概念       | 說明               |
| ---------- | ------------------ |
| Scale      | 映射實數範圍的尺度 |
| Zero point | 零值的整數表示     |
